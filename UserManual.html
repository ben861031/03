1. 系統概述與架構

「發文時程管制平台」是一款專為企業與機關團體打造的高效公文發文排程與簽核管理工具。本 v2.0 全新版本升級了 Firebase Firestore 雲端即時同步架構 與 手機版像素級響應式 UI (Mobile Responsive)，實現電腦與手機端跨裝置同步作業。

1.1 核心升級亮點

  • Firebase 雲端實時監聽 (`onSnapshot`)：多位同仁或主管同時開啟系統時，異動會即時同步，無需手動刷新。
  • 智慧型 1 小時 LocalStorage 低讀取快取：針對歷史「已發文」資料採用本地快取機制，節省超過 90% 的雲端 Reads 流量，載入速度提升 5 倍。
  • 跨系統快捷連結 (發文作業與線上簽核)：一鍵直達發文作業管理平台與線上簽核待辦清單，並可自動切換公司內網/外網模式。
  • 手機版極致優化 (Mobile Native Feel)：包含橫向流暢滾動的日期篩選膠囊 (Pill Tabs)、對稱選單按鈕與像素級水平對齊。

1.2 預設開啟與跳轉優先順序 (Waterfall Priority)

開啟系統或完成某項工作時，系統會依據緊急程度自動切換至最適頁面：

  1. 🥇 已逾期 (`overdue`)：最高優先（發文日期已過但未發文，紅字警告）。
  2. 🥈 今日待發 (`today`)：第二優先（發文日期為今天的案件）。
  3. 🥉 未設定日期 (`nodate`)：第三優先（缺乏預定日期的案件）。
  4. 🎖️ 尚待發文 (`pending`)：第四優先（所有未結案案件清單）。

2. 登入與權限稽核

2.1 系統登入

  • 輸入管理員配發的員工編號與密碼即可登入。
  • 系統採用持久化登入 Session，開啟瀏覽器無需重複輸入密碼。

2.2 登出與時間雙向稽核

  • 點擊側邊欄最下方「登出系統」可安全登出。
  • 使用者的每一次登入與登出時間，均會自動紀錄於後台資料庫中，供管理員進行權限與時間稽核。

4. 智慧批次匯入

💡 操作情境：每日從外部公文系統 (如 SinoSign) 複製待發文表格，一次貼入進行智慧對齊與同步。
  1. 點擊頂部藍色 「批次匯入」 按鈕。
  2. 將複製好的表格內容直接貼上 (Ctrl+V)。
  3. 點擊 「確認匯入」，系統自動進行欄位解析與同步預覽。
  4. 自動結案機制：若舊清單上的公文未出現在今日新貼入的清單中，系統會自動判定該公文已發文結案，並移入「累計已發」中。
⚠️ 高風險提醒：若貼入的資料不完整（僅貼上一部分），可能導致未貼入的案件被誤判為已完成。貼入前請確認資料完整性。

5. 日期與時程管理

  • 快捷日期設定：點擊發文日期欄位，可點擊「今天」、「明天」、「後天」快速代入日期。
  • 未來一週發文量預測：側邊欄下方顯示未來 7 天的待發量長條圖，點擊指定日期可快速篩選該日公文。
  • 逾期自動判定：發文日期早於今日且狀態仍為「待發」時，系統自動歸類至「已逾期」並以紅字警告。

6. 跨系統快捷連結 (發文作業與線上簽核)

6.1 開啟發文作業系統清單

  1. 點擊頂部 「發文作業」 按鈕。
  2. 系統會自動根據當前模式（公司內網/公司外網），於新分頁開啟「發文作業管理平台」清單網址，方便即時對照辦理。

6.2 開啟線上簽核待辦系統

  1. 點擊頂部 「線上簽核」 按鈕。
  2. 系統會自動以新分頁開啟「線上簽核系統」待辦清單，便於快速確認案件簽核狀態與流程。

7. 批次操作與刪除防呆

  • 批次完成：勾選多筆案件後點擊「批次完成」，一鍵標記為已發文並紀錄當前時間。
  • 批次刪除：勾選後點擊「批次刪除」，系統會顯示確認對話框防呆，確認後從雲端永久刪除。

8. 查詢與 Excel 匯出

8.1 即時關鍵字搜尋

在搜尋列輸入文號、主旨、承辦人或計畫編號，系統即時對目前清單進行過濾。

8.2 手機版橫向膠囊篩選列 (Pill Scroll Bar)

切換至「累計已發」時，手機版上方提供可流暢左右滑動的膠囊標籤欄 (全部、今天、本週、本月、自訂區間)，單手即可輕鬆切換區間。

8.3 匯出 Excel 清單

在「累計已發」頁面點擊 「匯出 Excel」，系統會自動下載完整 CSV 報表供歸檔備查。

9. 資料備份與還原

  • 匯出備份：點擊側邊欄「匯出備份」，可下載備份檔 (JSON 格式)。
  • 匯入備份：點擊側邊欄「匯入備份」，選擇先前備份檔即可還原歷史紀錄。建議在執行大量刪除前先進行備份。

10. 常見問題排除 (FAQ)

常見問題可能原因與排除方式
點擊表單編號沒有反應？ 系統已支援一鍵複製，點擊號碼會自動複製到剪貼簿並跳出已複製 Toast 提示。
為何 Firebase 讀取數會增加？ 系統已全面啟用 1 小時 LocalStorage 低讀取快取，常態使用 Reads 數極低。若執行批次匯入或清除瀏覽器快取時才會向雲端抓取新資料。
手機版畫面的按鈕有重疊現象？ 系統已全面提升為 Mobile Responsive 響應式佈局，若有異常請確認瀏覽器未開啟「強制縮放網頁」功能。
為什麼自動跳轉沒有跳到尚待發文？ 系統採取瀑布式流轉：已逾期 ➔ 今日待發 ➔ 未設定日期 ➔ 尚待發文。若未設定日期中有案件，會優先跳轉至該頁面提醒補齊日期。

附錄：狀態判斷與瀑布流規則

分類狀態判定條件說明
尚待發文狀態不為「已發文」之所有案件。
未設定日期狀態不為「已發文」，且發文日期空白。
今日待發狀態不為「已發文」，且發文日期等於本地電腦今日日期。
已逾期狀態不為「已發文」，且發文日期早於本地電腦今日日期。
累計已發狀態為「已發文」，並紀錄完成年月日時分秒。
