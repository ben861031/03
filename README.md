# 發文時程管理平台 v2.1.11

本版修正「總發公文自動匯入書籤」缺少一致分頁識別的問題。系統與新版書籤現在共用固定分頁名稱；Chrome 能辨識既有具名分頁時會重用，否則才開啟新分頁。書籤另加入導向識別碼、確認回覆與限時重試，避免既有分頁重新載入或網站尚未載入完成時漏接資料。

新版完整保留既有書籤對電子表單「總發」區域的擷取規則。發布網站後，請開啟 `bookmarklet/install.html`，刪除舊書籤並安裝「發文批次匯入（固定分頁）」；舊書籤仍可匯入，但不具固定分頁與可靠重送功能。

登入畫面的選項已精簡為同行顯示的「保持登入（共用電腦請勿勾選）」，括號內以紅字提醒。手機版四格資訊面板的上下列淡分隔線也改用一致權重的樣式規則，不再受桌機單雙列底色覆蓋。

本版延續「保持登入」選項。只有使用者在個人使用的裝置主動勾選時，Firebase 登入才會跨分頁、書籤新視窗與瀏覽器重新啟動保存；未勾選時仍維持原本較安全的分頁工作階段。明確登出會取消保持登入，系統不儲存員工編號或密碼。

本版也將暫時網路、App Check 或權限服務驗證異常與真正失去權限分開處理：暫時異常不再立即登出，而會保留登入、顯示獨立連線提示並進行有限次數重試；帳號停用、刪除或白名單權限確實移除時仍會拒絕存取並要求重新登入。

本版修正手機版公文資訊面板受桌機偶數列與觸控 hover 背景規則影響，導致部分公文四格呈白色、部分呈淡灰色的問題。現在每一筆公文的「計畫編號、承辦人、發文日期、顯示日期」均固定使用相同的柔和淡灰底色；桌機版原有單雙列效果不受影響。

本版將「本系統承辦帳號」與「白名單紀錄」合併為單一「承辦帳號與權限」清單。每位同仁只顯示一次，並清楚呈現登入帳號狀態、發文系統權限、最近一次成功登入時間，以及停用帳號、移除權限與永久刪除等操作。

「帳號與同仁白名單」視窗右上角新增固定的 X 關閉按鈕；即使手機清單已向下捲動，也能直接關閉視窗，底部原有的「關閉」按鈕仍保留。

本版將手機公文資訊區改為柔和摘要面板：取消明顯外框與中央直線、縮短面板高度，只在上下兩列之間保留一條左右內縮的淡分隔線，使版面更輕盈並減少表格感。

本版將手機公文卡片內原本四張獨立小卡，整合為單一 2×2 資訊面板。四格共用外框與中央分隔線，標題、數值、日期顏色及基準線均已統一，並縮減重複圓角造成的視覺雜訊。

這個資料夾可直接作為 GitHub Pages 網站內容上傳，請保留目前的資料夾層級，不要只上傳 `index.html`。

## 第一層檔案

- `index.html`：網站入口
- `manifest.webmanifest`：PWA 安裝設定
- `service-worker.js`：PWA 快取與離線頁控制；必須留在網站根目錄
- `offline.html`：離線提示頁

## 分類資料夾

- `assets/css/`：網站樣式
- `assets/js/`：網站程式與 Firebase 設定
- `assets/icons/`：網站、手機桌面與 PWA 圖示
- `bookmarklet/`：新版「總發公文自動匯入」書籤安裝頁與產生程式

## 上傳提醒
