# 發文時程管理平台 (Publishing Schedule Management Platform)

這是一個純前端執行的「發文時程管理平台」，旨在協助使用者有效追蹤與管理即將發布或待處理的公文/表單。系統提供直覺的狀態分類、未來一週的工作量預測，並支援批次匯入與資料備份，大幅提升發文作業的效率。

## ✨ 系統核心功能

1. **智慧狀態追蹤與分類**
   - **尚待發文**：統一列出所有尚未完成發文的案件。
   - **未設定日期**：快速篩選出尚未排定發文日期的案件。
   - **今日待發**：自動標示今天必須處理的發文。
   - **已逾期**：自動比對日期，將錯過發文時間的案件高亮顯示，以作警示。
   - **累計已發**：保存並可依據日期區間查詢歷史已發文紀錄。

2. **未來一週發文量預測 (Forecast)**
   - 側邊欄自動統計並顯示未來 7 天內每天預計要發送的公文數量。
   - 點擊對應日期即可快速過濾並查看當天的發文清單，方便工作排程。

3. **智慧批次匯入與操作**
   - **智慧批次匯入**：可直接將外部資料貼上，系統會自動解析並提供「新增公文」、「既有公文保留」、「自動標記已發文」的同步檢查與預覽，避免重複建立。
   - **批次完成 / 刪除**：支援多選功能，一鍵將多筆案件標示為完成或直接刪除。

4. **動態連結與內外網切換**
   - **智慧連結重寫**：針對電子簽核或發文系統的網址，支援自動偵測與重寫。
   - **內外網模式**：使用者可根據當前網路環境，自由切換連結為「公司內」或「公司外」，確保任何環境下皆能正確開啟表單與簽核系統。

5. **多維度查詢與排序**
   - **關鍵字搜尋**：支援即時搜尋表單編號、主旨、承辦人。
   - **欄位排序**：表格標題提供升降冪排序功能。
   - **分頁系統**：內建分頁機制，避免資料量過大時造成畫面卡頓。

6. **資料備份與匯出**
   - **本地暫存**：所有資料皆安全地儲存於瀏覽器的 LocalStorage 中。
   - **備份機制**：提供「匯出備份 (JSON)」與「匯入備份」功能，方便在不同電腦或瀏覽器間轉移資料。
   - **匯出 Excel**：可將「累計已發」的歷史紀錄一鍵匯出為 Excel 檔案，方便歸檔與統計。

---

## 🚀 使用方式

本系統為純前端架構，**無須安裝資料庫或架設伺服器**，資料完全保留於您的本機端：

### 步驟一：開啟系統
直接使用瀏覽器（推薦使用 Google Chrome 或 Microsoft Edge）雙擊專案資料夾中的 `index.html`。

### 步驟二：建立或匯入資料
- **批次匯入**：點擊上方「批次匯入」按鈕，將包含表單資訊的內容貼入並執行同步。
- **匯入備份**：如果您之前有匯出過 `.json` 備份檔，可透過左側選單的「匯入備份」還原資料。

### 步驟三：日常作業管理
- 透過左側的「**工作狀態**」快速檢視今日待辦或已逾期的案件。
- 點擊「**未來一週發文量**」中的日期，提前檢視未來的發文排程。
- 可透過表格右側的按鈕或多選後點擊「**批次完成**」，將案件推進至「累計已發」狀態。

### 步驟四：連結切換與對照
- 點擊表格內的「**操作**」按鈕，可同時開啟發文作業與電子表單進行對照。
- 若點擊連結無法開啟，請利用搜尋列旁的「**連結模式切換**」下拉選單，手動切換為對應的內網或外網模式。

### 步驟五：資料備份與報表
- 建議定期點擊左下角的「**匯出備份**」將資料下載為 `.json` 妥善保存。
- 進入「**累計已發**」頁籤，設定日期區間後，可點擊「**匯出 Excel**」產出報表。
