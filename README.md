# 發文時程管理平台 (Publishing Schedule Management Platform - Cloud Edition)

這是一個強大的「發文時程管理平台」，旨在協助使用者有效追蹤與管理即將發布或待處理的公文/表單。系統提供直覺的狀態分類、未來一週的工作量預測，並支援批次匯入與資料備份，大幅提升發文作業的效率。

**本系統已全面升級為 Cloud 版本，導入 Firebase 雲端資料庫與即時同步技術！**

## ✨ 系統核心功能

1. **雲端即時同步與帳號登入 (New Cloud Feature!)**
   - **安全登入**：採用 Firebase Authentication，以專屬帳號密碼登入系統，保護公文機密。
   - **雲端資料庫**：底層採用 Firebase Cloud Firestore，資料即時同步至雲端，徹底解決跨電腦/跨裝置資料不同步的問題。
   - **冷熱資料分流與極致效能**：系統智慧地將「活躍公文」與「歷史公文」分流讀取，搭配 Firestore 離線快取技術 (Offline Persistence)，在大幅節省網路流量的同時，提供超越傳統網頁的秒開體驗。

2. **智慧狀態追蹤與分類**
   - **尚待發文**：統一列出所有尚未完成發文的案件。
   - **未設定日期**：快速篩選出尚未排定發文日期的案件。
   - **今日待發**：自動標示今天必須處理的發文。
   - **已逾期**：自動比對日期，將錯過發文時間的案件高亮顯示，以作警示。
   - **累計已發**：保存並可依據日期區間查詢歷史已發文紀錄。

3. **瀑布式自動跳轉 (Waterfall Auto-Routing) (New!)**
   - 當您在特定過濾狀態（如「未設定日期」、「今日待發」、「已逾期」）下處理完最後一件公文時，系統將極致滑順地自動跳轉回「尚待發文」主頁，讓您的工作流暢無縫。

4. **未來一週發文量預測 (Forecast)**
   - 側邊欄自動統計並顯示未來 7 天內每天預計要發送的公文數量。
   - 點擊對應日期即可快速過濾並查看當天的發文清單，方便工作排程。

5. **智慧批次匯入與防呆機制**
   - **專屬文號綁定 (DocNo Binding)**：底層架構升級，全面採用 10 碼發文字號作為公文專屬唯一識別碼 (Primary Key)，徹底杜絕重複公文的產生。
   - **智慧批次匯入**：可直接將外部資料（或透過專屬書籤小工具）貼上，系統會自動解析並提供「新增公文」、「既有公文保留」、「自動標記已發文」的同步檢查與預覽。
   - **非同步防禦機制**：針對書籤小工具與雲端資料庫的傳輸時間差，內建嚴密的閘門機制，確保資料百分之百比對正確。

6. **動態連結與內外網切換**
   - **智慧連結重寫**：針對電子簽核或發文系統的網址，支援自動偵測與重寫。
   - **內外網模式**：使用者可根據當前網路環境，自由切換連結為「公司內」或「公司外」，確保任何環境下皆能正確開啟表單與簽核系統。

7. **現代化 UI/UX 與個性化主題**
   - **8 款高質感主題**：內建「清新全白、焦糖奶茶棕、靜謐森林綠、曜石黑」等多種主題，隨心一鍵切換，系統會自動記憶您的偏好。
   - **微動畫與細節設計**：全面導入現代字型、懸停微上浮動畫 (Micro-interactions) 與高質感的微透光按鈕 (Soft Buttons)，提供頂級的視覺體驗。

## 🚀 使用方式

### 步驟一：開啟系統與登入
直接透過專屬的 GitHub Pages 連結開啟系統。首次進入時，請輸入專屬帳號（您的員工編號）與預設密碼進行安全驗證。登入後，系統將自動從 Firebase 雲端同步最新資料。

### 步驟二：建立或匯入資料
- **書籤自動匯入**：透過專屬的瀏覽器書籤小工具，在公文系統中一鍵擷取資料並自動拋轉至本平台。
- **手動批次匯入**：點擊上方「批次匯入」按鈕，將包含表單資訊的內容貼入並執行同步。

### 步驟三：日常作業管理
- 透過左側的「**工作狀態**」快速檢視今日待辦或已逾期的案件。
- 點擊「**未來一週發文量**」中的日期，提前檢視未來的發文排程。
- 可透過表格右側的按鈕或多選後點擊「**批次完成**」，將案件推進至「累計已發」狀態，這些資料將即時備份至雲端。

### 步驟四：連結切換與對照
- 點擊表格內的「**操作**」按鈕，可同時開啟發文作業與電子表單進行對照。
- 若點擊連結無法開啟，請利用搜尋列旁的「**連結模式切換**」下拉選單，手動切換為對應的內網或外網模式。

### 步驟五：資料備份與報表
- 系統已具備 Firebase 即時雲端備份，您再也不用擔心更換電腦遺失資料。
- 為了線下留存，您仍可隨時點擊左下角的「**匯出備份**」將資料下載為 `.json`。
- 進入「**累計已發**」頁籤，設定日期區間後，可點擊「**匯出 Excel**」產出報表，方便後續稽核與統計。
