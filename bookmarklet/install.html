固定重用同一個系統分頁

本版沿用既有書籤的固定分頁名稱，因此舊書籤也能尋找同一個管理平台分頁。仍建議將下方藍色按鈕拖曳到 Chrome 書籤列；新版會先直接傳送到既有分頁、不重新載入，只有分頁未回應時才重新導向，並具備確認回覆與自動重送保護。

發文批次匯入（固定分頁）

電腦版：直接拖曳上方按鈕至書籤列。若無法拖曳，請使用下方複製方式。

  1. 開啟電子表單的「線上簽核」，確認頁面出現「總發」資料。
  2. 點選新書籤；若 Chrome 能辨識既有的固定分頁就會重用，否則才建立新分頁。重用時畫面可能短暫重新載入。
  3. 若尚未登入，資料會先由系統保留，登入完成後自動匯入。
